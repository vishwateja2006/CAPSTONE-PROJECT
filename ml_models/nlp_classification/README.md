# Model 3: Emergency Distress Message Classification

## Overview
Model 3 uses a fine-tuned DistilBERT transformer to classify raw crisis messages into 36 humanitarian categories with automated priority ranking.

## Performance Metrics
- **Accuracy:** 94.6%
- **Macro F1-Score:** 0.924 on 30,000 Appen test partition
- **Key Categories:** Medical Help (F1: 0.935), Clean Water (F1: 0.955), Child/Infant (F1: 0.945), Search & Rescue (F1: 0.905)
